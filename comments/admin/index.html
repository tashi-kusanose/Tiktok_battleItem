公開前の確認

編集の流れ

  1. 基本情報で名前と推しマを登録します。
  2. 今日の目標を入力し、定期文から必要な文を選びます。
  3. 「下書き保存」で自分用に保存。「確認」で公開文を確認します。
  4. 「公開する」でリスナー用ページに反映し、共有・保存からURLをコピーします。

編集途中の内容はリスナーには表示されません。非表示の文は下書きに残ります。別端末で編集した場合、古い内容で上書きする前に案内します。

未入力の値が残る文は、入力するか非表示にしてください。文字数は141文字を目安にチェックします。

キーボードアプリの辞書に追加した文は自動更新されません。目標や日時など変わる文は、最新のページからコピーしてください。
