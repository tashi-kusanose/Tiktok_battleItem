# Kazz PLAY 運用メモ

雑談ミニゲーム集とKazz配信ゲーム集を同じ参加ルームで利用するWebアプリ。
公開パス: `/games/`。既存のアイテム管理・コメント管理・歌リストのページやテーブルは変更しない。

## 使い方

1. ルーム名を入力し「ルームを作成」。管理リンクを本人だけで保管。
2. 「参加用リンク」をリスナーに共有。リスナーは名前を入力して参加。
3. ゲームを選び、お題や選択肢を編集して開始。
4. リスナーは自分のページで回答、投票、抽選、カード操作。
5. 配信者の「締切・結果発表」で区切り、必要なら「結果を保存」。次のゲームを選ぶ。

| 雑談ミニゲーム集 | 参加方法 |
| --- | --- |
| 質問ガチャ、コメントお題 | 140文字までの回答を1回送信 |
| 究極の2択、みんなのランキング | 1人1票。票数は即時共有 |
| みんなのミッション | 達成ボタン。達成人数を共有 |
| 全部ランダム | 上の5種から選んで開始設定を表示 |

| Kazz配信ゲーム集 | 参加方法 |
| --- | --- |
| ビンゴ | 1〜75。サーバー発行の個別カード。抽選済み数字を開けてビンゴ申告 |
| ルーレット | 配信者が設定した候補を等確率で抽選。結果を全員で閲覧 |
| ガチャガチャ | 各自1回。候補と1〜100の重みを設定し確率表示 |
| 参加者抽選 | 参加者から配信者が抽選。同じゲーム内は重複当選なし |
| 4択クイズ | 締切まで正解と他の人の回答を隠す |
| スロット | 各自1回。3リールをサーバー抽選し結果を共有 |
| カードめくり | 共有の6枚を先着順で選択。1人1枚。未開封の中身は非公開 |
| 宝箱 | 共有の6箱を先着順で選択。1人1箱。配信者は残りを開封可能 |

## 現在の運用範囲

- 1ルーム50人まで。ルームは48時間有効。人数は登録参加者数（オンライン人数ではない）。
- 13ゲーム＋ランダム選択。回答・抽選結果は現在のラウンドのみ保存。次のゲーム開始でリセットされるので必要な結果は事前にCSV保存する。
- 同じブラウザの保存情報、または管理リンクで復元。リスナー用URLには管理情報を含めない。
- 通信切断時は定期取得に切り替え、画面復帰時に再取得。自動再送しない。送信結果が不明な場合は再接続で送信済みを確認。
- ビンゴ途中参加も可能。カードを新規発行し、すでに呼ばれた数字を開けられる。受付を閉じると新規参加不可。
- TikTokのコメント・ギフト・配信映像とは自動連携しない。スマホ1台では画面切り替えが必要。2台の端末や対応端末の画面分割を推奨。
- 匿名の参加方式であり、端末やブラウザを変えた多重参加を完全には防げない。現金・景品の厳格な本人確認用途は想定しない。
- 50人満員・複数ルーム同時稼働の負荷検証、iPhone/Android実機の長時間確認は未実施。既存Supabaseと通信枠を共有するため段階的な試用から開始する。

## 構成・権限

- フロント: Vanilla JS/CSS。既存の固定バージョンSupabaseクライアント `comments/vendor/supabase-2.57.4.js` を再利用。
- API: Supabase Edge Function `kazz-games`。256-bitランダムの管理・参加トークンを `x-game-token` で送り、SHA-256ハッシュをDBで照合。サービスキーはEdge内のみ。
- DB: `kg_rooms` / `kg_players` / `kg_limits`。RLS有効、anon/authenticatedの直接アクセスと関数実行を剥奪。`kg_api` は SECURITY INVOKER・service_roleのみ。
- ルーム行のロックで更新を直列化。ラウンドID、抽選/開始時のrevision、1人1回答の制約をサーバー側で検査。
- Realtime BroadcastはランダムUUIDのトピックへrevisionだけ通知。正解・個別カード・回答・認証トークンは通知に含めない。通知受信後に認証済みAPIから再取得。
- クイズ正解・他人回答とカード・宝箱の未開封内容は締切前に参加者APIから除去。カードは本人だけに返却。
- サーバー暗号学乱数、拒否サンプリングで偏りを抑制。ガチャは整数重みに比例。
- レート制限: 作成はIP相当ハッシュ単位で6回/時間、参加60回/分、通常操作トークン単位150回/分。CORS許可originを限定。
- 期限から7日を過ぎたルームは次の新規ルーム作成時に削除。常時時刻指定の削除ジョブではない。
- セキュリティ検査では新規3テーブルの「RLS有効・ポリシーなし」は意図した全面拒否。既存機能の指摘には変更を加えていない。

## 配置と確認

DDLは `supabase/migrations/20260925121804_add_kazz_realtime_games.sql`。
Edgeソースは `supabase/functions/kazz-games/index.ts`。
フロントのAPI URL・publishable keyは公開可能な値のみ。
秘密トークン、検証用セッションファイル、サービスキーをリポジトリへ追加しない。
